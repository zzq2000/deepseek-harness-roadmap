# Deepseek Harness 学习

## 目标

Fork并拉取 deepseek harness（简称DSH）仓库，然后建立一个 html 的roadmap，目标是让我完全读懂 deepseek harness 的源码，并且能够基于源码进行二次开发。

## Deepseek Harness仓库

* 官方仓库：https://github.com/deepseek-ai/deepseek-harness
* 我的Fork：https://github.com/zzq2000/deepseek-harness

## Roadmap 要求

* HTML格式，与源码相互对照，注意美观和可交互性。
* 从零开始，逐步深入，易于理解。
* 每个章节后提一些思考的问题，检查我是否真的理解了。我在回答完这些问题后，应该可以调用Deepseek的API能够判断我是否回答正确。API调用相关在.env中。注意，每个问题都有对应的源码上下文，在判断的时候需要放入context中。

## 二次开发

在完成整个Harness学习之后，我应该能够理解整个DSH的框架，然后在AI的辅助下完成新的plugin。可以是新的工具调用、自进化、记忆机制、多智能体排布等研究问题。
